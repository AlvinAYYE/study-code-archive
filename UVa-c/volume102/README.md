<a id="uva-10200_prime-time"></a>
### UVa 10200 — Prime Time／質數時刻

- 原始碼：[10200_prime-time.c](10200_prime-time.c)
- 演算法：質數判定、前綴和（Prime, Prefix Sum）

**English description:** For every inclusive interval [a, b], evaluate n²+n+41 at each integer n and print the percentage of those values that are prime, rounded in the required format.

**中文詳細描述：** 每筆輸入區間端點 a、b；要對其中每個整數 n 計算 n²+n+41，統計結果為質數的比例並輸出百分比。完整作法可先預計算各 n 的質數性與前綴計數，使每個區間能快速取得質數個數

**中文解題思路：** 前綴和陣列預處理 0~10000 每個 n 是否為質數，O(1) 回答區間查詢。 ==========================================================================

### UVa 10205 — Stack 'em Up／紙牌洗牌排列置換複合模擬

- 原始碼：[10205_stack-em-up.c](10205_stack-em-up.c)
- 難度：UVa Star 1
- 演算法：simulation

**English description:** Given known 52-card shuffles (permutations) and a sequence of dealer shuffles, determine the final order of cards.

**中文詳細描述：** 給定若干套已知規則的 52 張撲克牌洗牌置換規則，依序模擬發牌員執行的洗牌動作，輸出最終牌組順序。

**English approach:** Start with identity array cards[i] = i. For each shuffle index k, apply deck[i] = old_deck[shuffles[k][i] - 1].

**中文解題思路：** 以 1..52 代表初始牌組，每次選定指定洗牌規則進行置換映射：new_deck[i] = old_deck[perm[i] - 1]。 ==========================================================================

### UVa 10212 — The Last Non-zero Digit.／排列數最後一個非零數字

**English description:** Find the last non-zero digit of the permutation P(N, M) = N! / (N - M)!.

<a id="uva-10213_how-many-pieces-of-land"></a>

### UVa 10213 — How Many Pieces of Land ?／多少塊土地？

- 原始碼：[10213_how-many-pieces-of-land.c](10213_how-many-pieces-of-land.c)
- 難度：Medium
- 演算法：math, combinatorics, euler-formula

**English description:** Given n points on a circle connected by chords with no 3 intersecting at a point, find the maximum number of pieces of land.

**中文詳細描述：** 圓周上有 n 個點，任兩點連一條弦且無三弦共點，求圓被切成的最大區域數量。

**English approach:** By Euler's formula V - E + F = 1: Pieces = 1 + C(n, 2) + C(n, 4) = 1 + n*(n-1)/2 + n*(n-1)*(n-2)*(n-3)/24.

**中文解題思路：** 由尤拉公式可得切割區域數為 1 + C(n, 2) + C(n, 4) = 1 + n*(n-1)/2 + n*(n-1)*(n-2)*(n-3)/24。 ==========================================================================
