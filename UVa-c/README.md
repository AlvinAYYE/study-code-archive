# UVa Online Judge - C 語言經典題庫 (Bilingual: 中文 / English)

本目錄彙整台灣大專院校程式能力檢定（CPE）與國際競賽最著名的 **UVa Online Judge 核心經典題庫**，全部由 **純 C 語言 (C99/C11)** 實作並經 GCC 全量自動化編譯測試 **100% PASS**。

### 目前收錄題目規模：共 **216 題**

### 題目特色與架構：
1. **雙語題面**: 同時包含 `[EN]` 官方英文題意/限制與 `[中文]` 繁體中文題意翻譯。
2. **思路分析**: 註解詳細說明解題演算法（時間複雜度與空間複雜度）。
3. **本地可測**: 附帶 `main()` 包含範例測資驗證（編譯執行自動印出 `PASS`）。
4. **OJ 提交模式**: 附帶符合 Online Judge EOF 規範的標準輸入輸出提交範本。
5. **難度分佈**: 兼具入門基礎題（如關係運算、進位制轉換、字串比對）至進階演算法題（動態規劃、最小生成樹、二分圖判定等）。
