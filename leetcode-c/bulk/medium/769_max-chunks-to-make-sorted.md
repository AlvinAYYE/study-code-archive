# LeetCode 0769. Max Chunks To Make Sorted

Title-CN: 最多可分成幾塊排序

## 題目

`arr` 是 `0` 到 `n-1` 的一個排列。你可以把它切成數個連續區塊，分別排序後再依原區塊順序串接；結果必須等於整個陣列排序後的結果。請回傳最多能切出的區塊數。

## 範例

1. 輸入：`arr = [4,3,2,1,0]`；輸出：`1`。切成多塊後分別排序，無法得到整體遞增順序。
2. 輸入：`arr = [1,0,2,3,4]`；輸出：`4`。可以切成 `[1,0]`、`[2]`、`[3]`、`[4]`。

## 限制

- `1 <= arr.length <= 10`
- `arr` 是 `0` 到 `n-1` 的互異排列

## 解題思路

1. 從左到右掃描，維護目前前綴看過的最大值 `maximum`。
2. 若掃到索引 `i` 時 `maximum == i`，代表前 `i+1` 個位置的值剛好是 `0` 到 `i`，不會有更右側的數字需要搬進這一段。
3. 因此可以在索引 `i` 後切一刀，區塊數加一。每個符合的位置都能獨立切開。

## 複雜度

時間 `O(n)`，額外空間 `O(1)`。

## C 函式簽名

`int maxChunksToSorted(int* arr, int arrSize)`
