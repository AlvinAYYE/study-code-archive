## 題目說明

沿街有一排房屋，每間房屋存有一定金額。相鄰兩間房屋的警報器相連，因此不能在同一晚偷相鄰房屋。給定每間房屋的金額 `nums`，回傳不觸發警報時可取得的最大金額。

## 範例

```text
輸入：nums = [1,2,3,1]
輸出：4
說明：偷第 1 間和第 3 間，取得 1 + 3 = 4。

輸入：nums = [2,7,9,3,1]
輸出：12
說明：偷第 1、3、5 間，取得 2 + 9 + 1 = 12。
```

## 限制

- `1 <= nums.length <= 100`。
- `0 <= nums[i] <= 400`。

## 解題步驟

1. 對每間房屋，選擇「不偷這間」或「偷這間」。
2. `oneBack` 保存處理到前一間時的最大金額，`twoBack` 保存處理到前兩間時的最大金額。
3. 偷目前房屋時可得 `twoBack + nums[i]`；不偷則沿用 `oneBack`。取兩者較大作為新答案。
4. 向右移動時更新兩個狀態，最後的 `oneBack` 就是全街最大金額。

## 複雜度

- 時間：`O(n)`，每間房屋計算一次。
- 額外空間：`O(1)`，只保存前兩個狀態。

## LeetCode C 函式簽名

```c
int rob(int* nums, int numsSize);
```
