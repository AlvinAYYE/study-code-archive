# LeetCode 0754. Reach a Number

Title-CN: 抵達目標數字

## 題目

你站在無限數線的 0。第 1 步必須移動 1 格，第 2 步移動 2 格，第 3 步移動 3 格，依此類推；每一步可選向左或向右。給定目標位置 `target`，求最少需要幾步才能抵達。

## 範例

1. `target = 2`，輸出 `3`：依序移動 `+1、-2、+3`，位置為 1、-1、2。
2. `target = 3`，輸出 `2`：依序移動 `+1、+2`。

## 限制

- `-10^9 <= target <= 10^9`
- `target != 0`

## 解題思路

1. 目標在左側或右側只差方向，因此先取 `abs(target)`，並假設每步都朝目標方向走。
2. 累加步長 `1 + 2 + ... + m`，直到總距離至少到達目標。
3. 若多走的距離是偶數，就把某一步從正向改成反向：距離會減少該步長的兩倍，因此可以剛好抵銷偶數差。若差為奇數，繼續增加一步，直到差變成偶數。
4. 第一次滿足「總距離不少於目標且差為偶數」的步數就是最少步數。

## 複雜度

時間 `O(sqrt(|target|))`，額外空間 `O(1)`。

## C 函式簽名

`int reachNumber(int target)`
