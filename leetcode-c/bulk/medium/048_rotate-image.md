# 0048. Rotate Image｜旋轉影像

- **難度**：中等
- **標籤**：陣列、數學、矩陣
- **題目連結**：[LeetCode 0048](https://leetcode.com/problems/rotate-image/)
- **C 程式**：[048_rotate-image.c](./048_rotate-image.c)

## 題目說明

給定 `n × n` 方形矩陣 `matrix`，將影像順時針旋轉 90 度。必須直接修改原矩陣，不能另建一個同尺寸矩陣。

## 範例

```text
輸入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
輸出：[[7,4,1],[8,5,2],[9,6,3]]

輸入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
輸出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

## 限制

- `matrix.length == matrix[i].length == n`。
- `1 <= n <= 20`。
- `-1000 <= matrix[i][j] <= 1000`。

## 解題步驟

1. 先沿主對角線轉置矩陣：交換 `matrix[row][column]` 和 `matrix[column][row]`，只需走訪對角線上方，避免重複交換。
2. 再把每一列左右反轉。
3. 轉置會把列與行交換，接著反轉每列，就得到順時針旋轉 90 度的結果。

例如 `[[1,2],[3,4]]` 先轉置為 `[[1,3],[2,4]]`，再反轉每列成為 `[[3,1],[4,2]]`。

## 複雜度

- 時間：`O(n^2)`，每個格子最多處理常數次。
- 額外空間：`O(1)`，直接原地交換。

## LeetCode C 函式簽名

```c
void rotate(int** matrix, int matrixSize, int* matrixColSize);
```
