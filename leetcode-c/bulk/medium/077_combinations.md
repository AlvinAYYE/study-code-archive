# 0077. Combinations｜組合

- **難度**：中等
- **標籤**：回溯
- **題目連結**：[LeetCode 0077](https://leetcode.com/problems/combinations/)
- **C 程式**：[077_combinations.c](./077_combinations.c)

## 題目說明

給定整數 `n` 和 `k`，從 `1` 到 `n` 中選出 `k` 個不同數字，回傳所有可能的組合。組合不看順序，所以 `[1,2]` 和 `[2,1]` 算同一種，只需輸出一次。

## 範例

```text
輸入：n = 4, k = 2
輸出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]

輸入：n = 1, k = 1
輸出：[[1]]
```

## 限制

- `1 <= n <= 20`。
- `1 <= k <= n`。

## 解題步驟

1. `path` 保存目前已選的數字，`depth` 是已選數量；每次只從比上一個數字大的候選值開始，避免重複順序。
2. 當 `depth == k`，複製 `path` 到答案，這就是一個完整組合。
3. 從 `start` 逐一嘗試候選數字，選入後遞迴搜尋下一個位置，再繼續嘗試下一個候選值。
4. 只走到 `n - (還需要選的數量) + 1`，確保剩下的數字足夠填滿組合，省掉無法完成的分支。
5. 先計算組合總數配置回傳陣列；每列組合和每列長度都分別配置記憶體，符合 LeetCode C API。

## 複雜度

- 時間：`O(k × C(n,k))`，需建立每個組合的 `k` 個數字。
- 額外空間：`O(k)` 遞迴路徑（不含回傳結果）；回傳結果占 `O(k × C(n,k))`。

## LeetCode C 函式簽名

```c
int** combine(int n, int k, int* returnSize, int** returnColumnSizes);
```
