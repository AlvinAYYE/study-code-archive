# 0062. Unique Paths｜不同路徑

- **難度**：中等
- **標籤**：數學、動態規劃、組合數學
- **題目連結**：[LeetCode 0062](https://leetcode.com/problems/unique-paths/)
- **C 程式**：[062_unique-paths.c](./062_unique-paths.c)

## 題目說明

機器人位於 `m × n` 網格左上角，要走到右下角。每一步只能往右或往下，回傳不同走法的總數。

## 範例

```text
輸入：m = 3, n = 7
輸出：28

輸入：m = 3, n = 2
輸出：3
說明：可依序走「右、下、下」、「下、下、右」或「下、右、下」。
```

## 限制

- `1 <= m, n <= 100`。
- 答案不超過 `2 × 10^9`。

## 解題步驟

1. `ways[column]` 表示目前列走到該欄的路徑數。
2. 第一列只能一路向右，因此每個格子的路徑數都是 1。
3. 掃描下一列時，走到目前欄可由上方下來，或由左方走來，所以 `ways[column] += ways[column - 1]`。
4. 掃描完成後，最後一欄的數值就是到達右下角的方法數。

## 複雜度

- 時間：`O(m × n)`。
- 額外空間：`O(n)`，只保存一列路徑數。

## LeetCode C 函式簽名

```c
int uniquePaths(int m, int n);
```
