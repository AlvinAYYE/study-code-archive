# 0018. 4Sum｜四數之和

- **難度**：中等
- **標籤**：陣列、雙指標、排序
- **題目連結**：[LeetCode 0018](https://leetcode.com/problems/4sum/)
- **C 程式**：[018_4sum.c](./018_4sum.c)

## 題目說明

給定整數陣列 `nums` 和目標值 `target`，找出所有由四個不同索引組成、總和等於 `target` 的四元組。不能重複回傳內容相同的四元組，答案順序不限。

## 範例

```text
輸入：nums = [1,0,-1,0,-2,2], target = 0
輸出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

輸入：nums = [2,2,2,2,2], target = 8
輸出：[[2,2,2,2]]
說明：有多種索引選法，但相同四元組只列一次。
```

## 限制

- `1 <= nums.length <= 200`。
- `-10^9 <= nums[i] <= 10^9`。
- `-10^9 <= target <= 10^9`。

## 解題步驟

1. 排序陣列，讓相同值相鄰，方便去重與移動指標。
2. 以 `i`、`j` 兩層迴圈固定前兩個數；`left`、`right` 搜尋剩餘區間。
3. `sum` 使用 `long long` 計算四數總和，避免 `int` 溢位。總和小於目標就增加 `left`；總和大於目標就減少 `right`。
4. 相等時複製四個數到答案，然後跳過左右端相同值；固定位置若重複也跳過。

## 複雜度

- 時間：`O(n^3)`，兩層固定迴圈加上雙指標掃描。
- 額外空間：搜尋使用 `O(1)`；不含排序與回傳答案的空間。

## LeetCode C 函式簽名

```c
int** fourSum(int* nums, int numsSize, int target, int* returnSize, int** returnColumnSizes);
```

`returnSize` 是答案組數，`returnColumnSizes[i]` 是第 `i` 組長度（固定為 4）。
