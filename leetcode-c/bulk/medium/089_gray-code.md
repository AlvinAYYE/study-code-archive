# 0089. Gray Code｜格雷碼

- **難度**：中等
- **標籤**：數學、位元運算、回溯
- **題目連結**：[LeetCode 0089](https://leetcode.com/problems/gray-code/)
- **C 程式**：[089_gray-code.c](./089_gray-code.c)

## 題目說明

回傳一組 `n` 位元的格雷碼序列，共有 `2^n` 個整數。序列從 `0` 開始，每個數字都在 `0` 到 `2^n - 1` 之間；相鄰兩個數字的二進位表示只能有一個位元不同，最後一個和第一個也必須只差一個位元。符合條件的序列不只一種，回傳任一種即可。

## 範例

```text
輸入：n = 2
輸出：[0,1,3,2]
說明：二進位為 00、01、11、10，相鄰項（含首尾）都只差一個位元。

輸入：n = 1
輸出：[0,1]
```

## 限制

- `1 <= n <= 16`。

## 解題步驟

1. 對每個整數 `i`，直接計算格雷碼 `i ^ (i >> 1)`：把 `i` 右移一位後，與原值做 XOR。
2. 依序令 `i` 從 `0` 到 `2^n - 1`，將公式結果放進回傳陣列。
3. 這個公式會讓相鄰項只有一個位元翻轉，也會讓最後一項和 `0` 只差一個位元。

## 複雜度

- 時間：`O(2^n)`，每個序列值計算一次。
- 額外空間：`O(1)` 工作空間；回傳陣列占 `O(2^n)`。

## LeetCode C 函式簽名

```c
int* grayCode(int n, int* returnSize);
```
