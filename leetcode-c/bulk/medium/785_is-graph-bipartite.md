# LeetCode 0785. Is Graph Bipartite?

Title-CN: 二分圖判斷

## 題目

給定一個無向圖的鄰接清單，節點編號為 `0` 到 `n-1`。二分圖表示可以把節點分成集合 A、B，且每條邊的一端在 A、另一端在 B。請判斷這個圖是否為二分圖；圖可能有多個互不相連的部分。

## 範例

1. 輸入：`[[1,2,3],[0,2],[0,1,3],[0,2]]`；輸出：`false`，其中有奇數長度的環，無法交替分組。
2. 輸入：`[[1,3],[0,2],[1,3],[0,2]]`；輸出：`true`，可分成 `{0,2}` 與 `{1,3}`。

## 限制

- `1 <= n <= 100`
- 不含自環；每條邊會在兩端的鄰接清單中都出現
- 每個鄰接清單中的節點不重複

## 解題思路

1. 用 `-1` 表示尚未分組，`0` 和 `1` 表示兩個集合。
2. 對每個尚未拜訪的節點啟動 BFS，先放入隊列並指定顏色 0，以處理不連通圖。
3. 對每條鄰接邊，若鄰居尚未上色，就塗成目前節點的相反顏色並加入隊列。
4. 若已上色的鄰居與目前節點同色，代表這條邊無法跨組，立即回傳 `false`；所有分量都通過則回傳 `true`。

## 複雜度

時間 `O(V + E)`，額外空間 `O(V)`。

## C 函式簽名

`bool isBipartite(int** graph, int graphSize, int* graphColSize)`
