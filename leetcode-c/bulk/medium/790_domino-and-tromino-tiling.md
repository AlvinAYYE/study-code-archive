# LeetCode 0790. Domino and Tromino Tiling

Title-CN: 骨牌與 L 形磚鋪板

## 題目

有一個高 2、寬 `n` 的棋盤，使用兩種磚塊完整鋪滿：`2 x 1` 長方形骨牌，以及由三格組成的 L 形 tromino。兩種磚塊都可以旋轉。請回傳不同鋪法數量，答案可能很大，因此回傳對 `10^9 + 7` 取餘數的結果。

## 範例

1. 輸入：`n = 3`；輸出：`5`。
2. 輸入：`n = 1`；輸出：`1`。

## 限制

- `1 <= n <= 1000`

## 解題思路

1. 定義 `dp[i]` 為完整鋪滿高 2、寬 `i` 棋盤的方法數。基礎值為 `dp[0]=1`、`dp[1]=1`、`dp[2]=2`。
2. 檢視最右端幾欄的覆蓋形狀，可分成兩種由 `dp[i-1]` 延伸的完整方式，以及一種由 `dp[i-3]` 延伸的方式，因此 `dp[i] = 2 * dp[i-1] + dp[i-3]`。
3. 逐欄計算，每一步立即取模，避免數值過大；乘法前使用 64 位元整數。

## 複雜度

時間 `O(n)`，額外空間 `O(n)`。

## C 函式簽名

`int numTilings(int n)`
