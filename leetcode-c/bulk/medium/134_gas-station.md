# 0134. Gas Station｜加油站

- **難度**：中等
- **標籤**：陣列、貪心
- **題目連結**：[LeetCode 0134](https://leetcode.com/problems/gas-station/)
- **C 程式**：[134_gas-station.c](./134_gas-station.c)

## 題目說明

有一條環狀路線和 `n` 個加油站。`gas[i]` 是第 `i` 站可加的油量，`cost[i]` 是從第 `i` 站開到下一站所需油量。油箱容量不限，出發時油箱為空。請找出能順時針繞行一圈的起點索引；若做不到回傳 `-1`。若有解，題目保證解唯一。

## 範例

```text
輸入：gas = [1,2,3,4,5], cost = [3,4,5,1,2]
輸出：3

輸入：gas = [2,3,4], cost = [3,4,3]
輸出：-1
```

## 限制

- `gas.length == cost.length`，且 `1 <= n <= 10^5`。
- `0 <= gas[i], cost[i] <= 10^4`。
- 若有解，起點唯一。

## 解題步驟

1. 每站的淨油量是 `gas[i] - cost[i]`。先累加全部淨油量；若總和小於 0，整圈油不夠，回傳 `-1`。
2. `tank` 記錄目前候選起點走到當前站的累積油量，起點一開始設為 0。
3. 若 `tank` 變成負數，表示目前起點到這一站之間的任何站都不能作為起點；將起點改為下一站並把油量歸零。
4. 總淨油量非負時，最後留下的候選起點就是唯一可行起點。

## 複雜度

- 時間：`O(n)`，掃描加油站一次。
- 額外空間：`O(1)`。

## LeetCode C 函式簽名

```c
int canCompleteCircuit(int* gas, int gasSize, int* cost, int costSize);
```
