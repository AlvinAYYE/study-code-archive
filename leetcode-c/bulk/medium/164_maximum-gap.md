# 0164. Maximum Gap｜最大間距

- **難度**：中等
- **標籤**：陣列、排序、桶排序
- **題目連結**：[LeetCode 0164](https://leetcode.com/problems/maximum-gap/)
- **C 程式**：[164_maximum-gap.c](./164_maximum-gap.c)

## 題目說明

給定整數陣列，將數字排序後，找出相鄰兩個數字之間最大的差值。陣列少於兩個元素時回傳 `0`。要求線性時間並使用線性額外空間。

## 範例

```text
輸入：nums = [3,6,9,1]
輸出：3
說明：排序後為 [1,3,6,9]，最大相鄰差為 3。

輸入：nums = [10]
輸出：0
```

## 限制

- `1 <= nums.length <= 10^5`。
- `0 <= nums[i] <= 10^9`。

## 解題步驟

1. 找出陣列最小值和最大值。若所有值相同，答案為 0。
2. 把數值範圍切成 `n - 1` 個以上的桶；桶寬取 `ceil((最大值 - 最小值) / (n - 1))`。
3. 將每個數放進對應桶，只記錄該桶的最小值與最大值。桶內的差距不會大於桶寬，最大相鄰差必定出現在相鄰的非空桶之間。
4. 由左到右掃描非空桶，以目前桶最小值減前一個非空桶最大值，更新最大差。

## 複雜度

- 時間：`O(n)`，找範圍、放桶與掃描桶都為線性。
- 額外空間：`O(n)`，桶數不超過元素數量。

## LeetCode C 函式簽名

```c
int maximumGap(int* nums, int numsSize);
```
