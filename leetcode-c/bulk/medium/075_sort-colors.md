# 0075. Sort Colors｜顏色排序

- **難度**：中等
- **標籤**：陣列、雙指標、排序
- **題目連結**：[LeetCode 0075](https://leetcode.com/problems/sort-colors/)
- **C 程式**：[075_sort-colors.c](./075_sort-colors.c)

## 題目說明

陣列中的 `0`、`1`、`2` 分別代表紅、白、藍。請直接排序原陣列，讓顏色依紅、白、藍排列，也就是所有 `0` 在前、`1` 在中間、`2` 在最後。不能呼叫程式庫排序函式；進階要求是只掃描一次並使用常數額外空間。

## 範例

```text
輸入：nums = [2,0,2,1,1,0]
輸出：       [0,0,1,1,2,2]

輸入：nums = [2,0,1]
輸出：       [0,1,2]
```

## 限制

- `1 <= nums.length <= 300`。
- 每個 `nums[i]` 都是 `0`、`1` 或 `2`。

## 解題步驟

1. 用 `low` 表示下一個應放 `0` 的位置，`current` 掃描尚未分類的元素，`high` 表示下一個應放 `2` 的位置。
2. 遇到 `0`，和 `low` 交換，然後 `low`、`current` 都右移；因為換過來的值已在分類好的區域。
3. 遇到 `1`，它已在正確的中間區域，只把 `current` 右移。
4. 遇到 `2`，和 `high` 交換並把 `high` 左移；換來的值還未檢查，所以 `current` 暫時不動。
5. 當 `current > high`，整個陣列就分成 `0`、`1`、`2` 三段。

## 複雜度

- 時間：`O(n)`，每個元素至多檢查一次。
- 額外空間：`O(1)`。

## LeetCode C 函式簽名

```c
void sortColors(int* nums, int numsSize);
```
