# LeetCode 0775. Global and Local Inversions

Title-CN: 全域與區域反轉

## 題目

給定 `0` 到 `n-1` 的一個排列。若 `i < j` 且 `nums[i] > nums[j]`，這一對稱為全域反轉；若 `nums[i] > nums[i+1]`，則是區域反轉。請判斷全域反轉數量是否剛好等於區域反轉數量。

## 範例

1. 輸入：`nums = [1,0,2]`；輸出：`true`。只有 `(0,1)` 這一個全域反轉，而且它也是區域反轉。
2. 輸入：`nums = [1,2,0]`；輸出：`false`。`1 > 0` 與 `2 > 0` 形成兩個全域反轉，但只有相鄰的 `(1,2)` 是區域反轉。

## 限制

- `1 <= nums.length <= 10^5`
- `nums` 是 `0` 到 `n-1` 的互異排列

## 解題思路

1. 每個區域反轉也一定是全域反轉；要讓兩種數量相等，不能再有跨越多個索引的反轉。
2. 對 `0..n-1` 的排列，這等價於每個值只能離開它的正確索引最多一格：檢查 `abs(nums[i] - i) <= 1`。
3. 一旦某個值偏移超過一格，必然造成至少一個非相鄰的全域反轉，回傳 `false`；全部符合就回傳 `true`。

## 複雜度

時間 `O(n)`，額外空間 `O(1)`。

## C 函式簽名

`bool isIdealPermutation(int* nums, int numsSize)`
