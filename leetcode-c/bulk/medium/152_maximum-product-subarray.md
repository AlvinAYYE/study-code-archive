# 0152. Maximum Product Subarray｜乘積最大的子陣列

- **難度**：中等
- **標籤**：陣列、動態規劃
- **題目連結**：[LeetCode 0152](https://leetcode.com/problems/maximum-product-subarray/)
- **C 程式**：[152_maximum-product-subarray.c](./152_maximum-product-subarray.c)

## 題目說明

給定整數陣列 `nums`，找出乘積最大的連續子陣列，回傳它的乘積。子陣列必須連續，不能跳過中間元素；答案保證可放入 32 位元有號整數。

## 範例

```text
輸入：nums = [2,3,-2,4]
輸出：6
說明：[2,3] 的乘積是 6。

輸入：nums = [-2,0,-1]
輸出：0
說明：[-2,-1] 不連續，不能把它們當成同一個子陣列。
```

## 限制

- `1 <= nums.length <= 2 × 10^4`。
- `-10 <= nums[i] <= 10`。
- 任一連續子陣列的乘積都可放入 32 位元有號整數。

## 解題步驟

1. 每個位置同時記錄「以此位置結尾的最大乘積」和「最小乘積」。負數乘上最小負數可能變成最大正數，所以兩者都要保留。
2. 讀到負數時，先交換最大與最小狀態，讓後續相乘方向正確。
3. 新的最大、最小乘積，分別在「從目前數字重新開始」和「延伸前一段乘積」中取最大或最小。
4. 每一步都用當前最大乘積更新全域答案。

## 複雜度

- 時間：`O(n)`，每個元素處理一次。
- 額外空間：`O(1)`。

## LeetCode C 函式簽名

```c
int maxProduct(int* nums, int numsSize);
```
