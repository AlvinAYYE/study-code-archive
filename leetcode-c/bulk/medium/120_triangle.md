# 0120. Triangle｜三角形最小路徑和

- **難度**：中等
- **標籤**：陣列、動態規劃
- **題目連結**：[LeetCode 0120](https://leetcode.com/problems/triangle/)
- **C 程式**：[120_triangle.c](./120_triangle.c)

## 題目說明

給定一個整數三角形，從頂端出發走到最底列。每一步只能從目前位置往下一列的同索引或下一個索引移動。請回傳沿途數字總和的最小值。

## 範例

```text
輸入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
輸出：11
說明：最小路徑是 2 → 3 → 5 → 1，總和為 11。

輸入：triangle = [[-10]]
輸出：-10
```

## 限制

- `1 <= triangle.length <= 200`。
- 第一列長度為 1，每列比上一列多一個元素。
- `-10^4 <= triangle[i][j] <= 10^4`。

## 解題步驟

1. 從最底列開始，令 `best[column]` 表示從該列該位置走到底的最小總和；最底列的答案就是元素本身。
2. 從倒數第二列往上處理。每個位置下一步只能走到下一列的 `column` 或 `column + 1`。
3. 取這兩個位置較小的累積和，再加上目前格子的值，覆寫 `best[column]`。
4. 逐列往頂端更新後，`best[0]` 就是從頂端到底端的最小路徑和。

## 複雜度

- 時間：`O(n²)`，處理三角形中的每個元素一次。
- 額外空間：`O(n)`，只保存最底列長度的 DP 陣列。

## LeetCode C 函式簽名

```c
int minimumTotal(int** triangle, int triangleSize, int* triangleColSize);
```
