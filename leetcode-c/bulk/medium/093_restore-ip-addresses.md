# 0093. Restore IP Addresses｜復原 IP 位址

- **難度**：中等
- **標籤**：字串、回溯
- **題目連結**：[LeetCode 0093](https://leetcode.com/problems/restore-ip-addresses/)
- **C 程式**：[093_restore-ip-addresses.c](./093_restore-ip-addresses.c)

## 題目說明

給定只含數字的字串 `s`，在數字之間插入三個句點，找出所有有效的 IPv4 位址。每個位址必須有四段，每段是 `0` 到 `255` 的整數；除單獨的 `0` 外，段落不能有前導零。不能重排或刪除原字串的數字，答案順序不限。

## 範例

```text
輸入：s = "25525511135"
輸出：["255.255.11.135","255.255.111.35"]

輸入：s = "0000"
輸出：["0.0.0.0"]

輸入：s = "101023"
輸出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
```

## 限制

- `1 <= s.length <= 20`。
- `s` 只包含數字。

## 解題步驟

1. 從左到右依序建立四個區段；每一段只嘗試取 1、2 或 3 個字元。
2. 若一段長度大於 1 且第一個字元是 `0`，就跳過，因為它有前導零。
3. 將目前片段轉成整數；大於 255 就停止增加長度，因為更長的片段只會更大。
4. 遞迴處理下一段。若已建立四段且剛好用完全部數字，就複製目前字串到答案。
5. 若剩餘字元數少於剩餘段數，或多於剩餘段數的三倍，直接剪枝。

## 複雜度

- 時間：`O(1)`，最多嘗試 `3^4` 種分段方式；不含複製答案字串的成本。
- 額外空間：`O(1)` 工作空間；回傳字串與指標陣列依答案數量配置。

## LeetCode C 函式簽名

```c
char** restoreIpAddresses(char* s, int* returnSize);
```
