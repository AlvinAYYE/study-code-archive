# 0165. Compare Version Numbers｜比較版本號

- **難度**：中等
- **標籤**：雙指標、字串
- **題目連結**：[LeetCode 0165](https://leetcode.com/problems/compare-version-numbers/)
- **C 程式**：[165_compare-version-numbers.c](./165_compare-version-numbers.c)

## 題目說明

版本號由數字修訂段組成，段與段之間以句點分隔，例如 `1.2.10`。比較時由左到右逐段比較整數值，前導零不影響數值；若某版本段數較少，缺少的段視為 `0`。若 `version1` 較小回傳 `-1`，相等回傳 `0`，較大回傳 `1`。

## 範例

```text
輸入：version1 = "1.2", version2 = "1.10"
輸出：-1

輸入：version1 = "1.01", version2 = "1.001"
輸出：0

輸入：version1 = "1.0", version2 = "1.0.0.0"
輸出：0
```

## 限制

- 兩個版本字串長度介於 `1` 到 `500`。
- 字串只包含數字和句點，且格式有效。
- 每段數值可存入 32 位元有號整數。

## 解題步驟

1. 用兩個索引分別讀取兩個版本字串的下一段。
2. 將句點之間的數字讀成整數；轉換時自然忽略前導零。
3. 任一字串已讀完時，該版本缺少的段當作 0。
4. 比較目前兩段：不同就回傳較小或較大的結果；相同就繼續讀下一段。
5. 所有段都相同時回傳 0。

## 複雜度

- 時間：`O(m + n)`，每個版本字元最多掃描一次。
- 額外空間：`O(1)`。

## LeetCode C 函式簽名

```c
int compareVersion(char* version1, char* version2);
```
