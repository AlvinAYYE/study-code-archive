# LeetCode 0698. Partition to K Equal Sum Subsets

Title-CN: 劃分為 k 個等和子集合

## 題目

給定正整數陣列 `nums` 和整數 `k`。請把陣列中的每個元素恰好使用一次，分成 `k` 個非空子集合。若所有子集合的元素總和都相同，回傳 `true`，否則回傳 `false`。每組目標總和就是陣列總和除以 `k`。

## 範例

1. 輸入：`nums = [4,3,2,3,5,2,1], k = 4`；輸出：`true`。可分為 `[5]`、`[1,4]`、`[2,3]`、`[2,3]`，每組總和都是 5。
2. 輸入：`nums = [1,2,3,4], k = 3`；輸出：`false`，總和無法平均分成 3 組。

## 限制

- `1 <= k <= nums.length <= 16`
- `1 <= nums[i] <= 10^4`
- 每個不同數值在陣列中最多出現 4 次

## 解題思路

1. 若所有數字總和不能被 `k` 整除，立刻回傳 `false`；否則每組目標值為 `total / k`。
2. 用一個位元遮罩 `mask` 表示哪些索引已使用。`dp[mask]` 保存這些數字填入目前一組後的餘數；`-1` 代表這個狀態無法到達。
3. 從可達狀態出發，逐個嘗試加入尚未使用的數字。若加上後超過目標值就跳過；剛好填滿一組時餘數變成 0，自然開始下一組。
4. 所有元素都用完且餘數為 0，代表剛好填滿整數個目標組，回傳 `true`。

## 複雜度

時間 `O(n * 2^n)`，額外空間 `O(2^n)`。

## C 函式簽名

`bool canPartitionKSubsets(int* nums, int numsSize, int k)`
