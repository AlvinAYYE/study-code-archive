# LeetCode 0789. Escape The Ghosts

Title-CN: 逃離鬼魂

## 題目

你從無限二維格子的 `(0,0)` 出發，要走到 `target`。每回合玩家和所有鬼魂可以各自選擇上下左右移動一格，或留在原地；所有移動同時發生。玩家只有在比所有鬼魂更早抵達目標時才算逃脫，和鬼魂同時抵達也算失敗。請判斷玩家是否能逃脫。

## 範例

1. `ghosts = [[1,0],[0,3]], target = [0,1]`，輸出 `true`。玩家一步到達，鬼魂至少需要兩步。
2. `ghosts = [[1,0]], target = [2,0]`，輸出 `false`。鬼魂可以先到目標攔截。
3. `ghosts = [[2,0]], target = [1,0]`，輸出 `false`。玩家和鬼魂可在同一回合到達，仍算被抓。

## 限制

- `1 <= ghosts.length <= 100`
- 所有座標介於 `-10^4` 和 `10^4`
- 多個鬼魂可以位於同一位置

## 解題思路

1. 在格子上走到 `(x,y)` 的最少步數是曼哈頓距離 `|x| + |y|`。
2. 算出玩家從原點到目標的距離，再逐一算每隻鬼魂到目標的距離。
3. 只要有鬼魂距離不大於玩家，鬼魂就能先到或同時到目標，玩家無法保證逃脫；否則所有鬼魂都來不及攔截。

## 複雜度

時間 `O(g)`，額外空間 `O(1)`；`g` 是鬼魂數量。

## C 函式簽名

`bool escapeGhosts(int** ghosts, int ghostsSize, int* ghostsColSize, int* target, int targetSize)`
