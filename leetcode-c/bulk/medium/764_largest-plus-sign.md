# LeetCode 0764. Largest Plus Sign

Title-CN: 最大加號標誌

## 題目

有一個 `n x n` 網格，起初每格都是 1。`mines[i] = [x,y]` 表示位置 `(x,y)` 改成 0。加號的中心和上下左右四條臂都必須是 1；階數 `k` 表示中心為 1，四個方向各延伸 `k-1` 格。請回傳網格中最大的加號階數；若沒有任何 1，回傳 0。

## 範例

1. 輸入：`n = 5, mines = [[4,2]]`；輸出：`2`。最大的加號中心可向四個方向各延伸 1 格。
2. 輸入：`n = 1, mines = [[0,0]]`；輸出：`0`，唯一格子是 0。

## 限制

- `1 <= n <= 500`
- `1 <= mines.length <= 5000`
- 每個座標都在網格內，且座標配對不重複

## 解題思路

1. 建立一維陣列表示網格，先全部設為 1，再將 mines 指定的位置設為 0。
2. 每列由左向右、再由右向左掃描，計算每格在水平方向連續 1 的長度，並保留兩側長度的較小值。
3. 每欄由上向下、再由下向上掃描，以相同方式納入垂直方向的連續長度。
4. 每格最後保存的值就是以它為中心可形成的最大加號階數；取全網格最大值。

## 複雜度

時間 `O(n^2 + minesSize)`，額外空間 `O(n^2)`。

## C 函式簽名

`int orderOfLargestPlusSign(int n, int** mines, int minesSize, int* minesColSize)`
