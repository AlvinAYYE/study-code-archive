# 0015. 3Sum｜三數之和

- **難度**：中等
- **標籤**：陣列、雙指標、排序
- **題目連結**：[LeetCode 0015](https://leetcode.com/problems/3sum/)
- **C 程式**：[015_3sum.c](./015_3sum.c)

## 題目說明

給定整數陣列 `nums`，找出所有由三個不同索引組成、總和為 `0` 的三元組。答案中不能有內容相同的三元組，輸出順序不限。

## 範例

```text
輸入：nums = [-1,0,1,2,-1,-4]
輸出：[[-1,-1,2],[-1,0,1]]
說明：-1 + -1 + 2 = 0；-1 + 0 + 1 = 0。相同組合只回傳一次。

輸入：nums = [0,1,1]
輸出：[]

輸入：nums = [0,0,0]
輸出：[[0,0,0]]
```

## 限制

- `3 <= nums.length <= 3000`。
- `-10^5 <= nums[i] <= 10^5`。

## 解題步驟

1. 將陣列排序，使相同數字相鄰，也讓雙指標能依總和方向移動。
2. 用 `i` 固定第一個數；`left = i + 1`、`right = numsSize - 1` 搜尋剩下兩個數。
3. 將三數相加：小於 0 就增加 `left`；大於 0 就減少 `right`；等於 0 就把三個值複製到答案。
4. 固定值重複時跳過；找到一組答案後也跳過相同的左右值，避免重複結果。

## 複雜度

- 時間：`O(n^2)`，排序後固定一個數並線性掃描另外兩個數。
- 額外空間：搜尋使用 `O(1)`；不含排序和回傳答案的空間。

## LeetCode C 函式簽名

```c
int** threeSum(int* nums, int numsSize, int* returnSize, int** returnColumnSizes);
```

函式配置答案列；`returnSize` 是三元組數量，`returnColumnSizes[i]` 是第 `i` 列長度（固定為 3）。
