# LeetCode 1108. Defanging an IP Address

**難度：Easy**

## 題意完整翻譯

給定一個有效的 IPv4 位址，請把其中每個句點 . 替換成字串 [.]，並回傳轉換後的新字串。

## 範例

1. address = "1.1.1.1" → "1[.]1[.]1[.]1"
2. address = "255.100.50.0" → "255[.]100[.]50[.]0"

## 限制

- 輸入一定是有效的 IPv4 位址

## 解題思路

1. 先計算位址長度，配置最多三倍長度再加結尾符號的空間。
2. 逐字讀取位址：遇到句點就依序寫入 [.]；遇到數字就原樣複製。
3. 在新字串最後補上結尾符號並回傳。

## 複雜度

- 時間：O(n)
- 空間：O(n)（回傳字串）

## C 函式簽名

~~~c
char* defangIPaddr(char* address);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
