# LeetCode 1051. Height Checker

**難度：Easy**

## 題意完整翻譯

學校要替學生拍年度合照，學生應按身高由矮到高排成一列。給定目前順序 heights，請先想像依身高升冪排序後的正確順序 expected，再回傳目前陣列與正確順序在多少個索引位置不同。

## 範例

1. heights = [1,1,4,2,1,3] → 3（排序後為 [1,1,1,2,3,4]，索引 2、4、5 不同）
2. heights = [5,1,2,3,4] → 5
3. heights = [1,2,3,4,5] → 0

## 限制

- 1 <= heights.length <= 100
- 1 <= heights[i] <= 100

## 解題思路

1. 複製 heights，避免改動題目提供的目前順序。
2. 將複製陣列由小到大排序，這就是 expected。
3. 逐一比較兩個陣列相同索引的值，每次不同就把答案加一。

## 複雜度

- 時間：O(n log n)
- 空間：O(n)（排序用的複製陣列）

## C 函式簽名

~~~c
int heightChecker(int* heights, int heightsSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
