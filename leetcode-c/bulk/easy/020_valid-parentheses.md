# 0020. Valid Parentheses《有效的括號》

- **難度**：Easy
- **標籤**：string、stack
- **題目連結**：https://leetcode.com/problems/valid-parentheses/
- **程式碼**：[`020_valid-parentheses.c`](./020_valid-parentheses.c)

## 題目說明

給定只包含小括號 `()`、中括號 `[]`、大括號 `{}` 的字串 `s`，判斷括號是否有效。有效字串必須同種類配對、依正確順序閉合，而且每個右括號都要對應到先前尚未閉合的左括號。

## 範例

```text
輸入：s = "()"
輸出：true

輸入：s = "()[]{}"
輸出：true

輸入：s = "(]"
輸出：false

輸入：s = "([])"
輸出：true

輸入：s = "([)]"
輸出：false
說明：括號閉合順序錯誤。
```

## 限制

- `1 <= s.length <= 10^4`
- `s` 只包含 `()[]{}`。

## 直觀解題思路

1. 由左往右掃描，遇到左括號就壓入堆疊。
2. 遇到右括號時，它只能與堆疊頂端最近出現的左括號配對。
3. 若堆疊為空或括號種類不符，立即回傳 `false`。
4. 全部掃描完後，堆疊必須為空，否則仍有左括號未閉合。

- 時間複雜度：`O(n)`
- 額外空間複雜度：`O(n)`

## 官方 C 函式簽名

```c
bool isValid(char* s);
```
