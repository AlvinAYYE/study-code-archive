# LeetCode 257. Binary Tree Paths

**難度：Easy**

## 題意完整翻譯

給定二元樹根節點 root，請回傳所有從根節點到葉節點的路徑。葉節點是沒有左、右子節點的節點。每條路徑以節點值組成，節點之間使用 -> 連接。

## 範例

1. root = [1,2,3,null,5] → ["1->2->5","1->3"]
2. root = [1] → ["1"]

## 限制

- 節點數介於 1 到 100
- -100 <= Node.val <= 100

## 解題思路

1. 從根節點開始做深度優先搜尋，並把目前走過的節點值依序寫入路徑字串。
2. 走到非葉節點時，在路徑後加上 ->，再遞迴走訪存在的左右子節點。
3. 走到葉節點時，複製目前路徑字串加入答案。
4. 搜尋完回傳所有路徑字串。

## 複雜度

- 時間：O(n + 輸出字元總數)
- 空間：O(輸出字元總數 + h)，h 為遞迴堆疊高度

## C 函式簽名

~~~c
char** binaryTreePaths(struct TreeNode* root, int* returnSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
