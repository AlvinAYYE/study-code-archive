# LeetCode 1137. N-th Tribonacci Number

**難度：Easy**

## 題意完整翻譯

Tribonacci 數列定義為 T0 = 0、T1 = 1、T2 = 1；從 T3 開始，每一項等於前面三項相加，也就是 Tn = Tn-1 + Tn-2 + Tn-3。給定 n，請回傳 Tn。

## 範例

1. n = 4 → 4（T3 = 0 + 1 + 1 = 2，T4 = 1 + 1 + 2 = 4）
2. n = 25 → 1389537

## 限制

- 0 <= n <= 37
- 答案保證可用 32 位元有號整數表示

## 解題思路

1. n 為 0、1、2 時直接回傳對應初始值。
2. 用三個變數保存目前連續的三項 T(i-3)、T(i-2)、T(i-1)。
3. 從 i = 3 算到 n：新值是三項相加，接著將三個變數往前移一格。
4. 回傳最後算出的 Tn。

## 複雜度

- 時間：O(n)
- 空間：O(1)

## C 函式簽名

~~~c
int tribonacci(int n);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
