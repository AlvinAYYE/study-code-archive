# 0070. Climbing Stairs《爬樓梯》

- **難度**：Easy
- **標籤**：數學、動態規劃
- **題目連結**：https://leetcode.com/problems/climbing-stairs/

## 題目說明

你正在爬一座有 `n` 階的樓梯，每次可以往上走 1 階或 2 階。請計算總共有幾種不同走法能到達頂端。走法的順序不同就算不同，例如「先走 1 階再走 2 階」和「先走 2 階再走 1 階」是兩種走法。

## 範例

```text
輸入：n = 2
輸出：2
說明：可以走 1 + 1，或直接走 2。

輸入：n = 3
輸出：3
說明：可以走 1 + 1 + 1、1 + 2，或 2 + 1。
```

## 限制

- `1 <= n <= 45`

## 解題思路

1. 到第 `i` 階的最後一步只能從第 `i-1` 階走 1 階，或從第 `i-2` 階走 2 階。
2. 因此 `ways(i) = ways(i-1) + ways(i-2)`。起始值是 `ways(1)=1`、`ways(2)=2`。
3. 從第 3 階往上計算，每次只保留前兩階的答案；算出目前答案後，把兩個記錄往前更新。

**複雜度**：時間 `O(n)`，額外空間 `O(1)`。

## C 函式簽名

```c
int climbStairs(int n);
```
