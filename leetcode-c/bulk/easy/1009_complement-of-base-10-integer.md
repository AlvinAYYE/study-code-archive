# LeetCode 1009. Complement of Base 10 Integer

**難度：Easy**

## 題意完整翻譯

給定非負整數 n，先寫出它不含前導零的二進位表示，再將每個位元 0 和 1 互換，最後把結果轉回十進位並回傳。特別地，0 的二進位表示是 0，因此它的補數是 1。

## 範例

1. n = 5 → 2（101₂ 翻轉為 010₂，也就是 2）
2. n = 7 → 0（111₂ 翻轉為 000₂）
3. n = 10 → 5（1010₂ 翻轉為 0101₂）

## 限制

- 0 <= n < 10⁹

## 解題思路

1. n 為 0 時直接回傳 1。
2. 從 1 開始左移，直到 mask 大於 n；此時 mask 的二進位只有最高位多一個 1。
3. mask - 1 會形成與 n 位數相同、每一位都是 1 的遮罩。將 n 與遮罩做 XOR，就能只翻轉 n 的有效位元。

## 複雜度

- 時間：O(log n)
- 空間：O(1)

## C 函式簽名

~~~c
int bitwiseComplement(int n);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
