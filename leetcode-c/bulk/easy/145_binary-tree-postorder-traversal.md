# LeetCode 145. Binary Tree Postorder Traversal

**難度：Easy**

## 題意完整翻譯

給定二元樹的根節點 root，請回傳後序走訪結果。後序走訪的順序是：先走訪左子樹，再走訪右子樹，最後處理目前節點。

## 範例

1. root = [1,null,2,3] → [3,2,1]
2. root = [1,2,3,4,5,null,8,null,null,6,7,9] → [4,6,7,5,2,9,8,3,1]
3. root = [] → []
4. root = [1] → [1]

## 限制

- 節點數介於 0 到 100
- -100 <= Node.val <= 100

## 解題思路

1. 建立一個結果陣列和目前寫入位置。
2. 遞迴遇到節點時，先走訪左子樹，再走訪右子樹。
3. 左右子樹處理完後，才把目前節點的值放入結果。

## 複雜度

- 時間：O(n)，每個節點走訪一次
- 空間：O(n) 回傳陣列，另有 O(h) 遞迴堆疊

## C 函式簽名

~~~c
int* postorderTraversal(struct TreeNode* root, int* returnSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
