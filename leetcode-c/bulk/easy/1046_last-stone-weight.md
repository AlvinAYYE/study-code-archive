# LeetCode 1046. Last Stone Weight

**難度：Easy**

## 題意完整翻譯

給定每顆石頭的正整數重量。每回合取出目前最重的兩顆 x 和 y（x <= y）互相碰撞：若 x == y，兩顆都消失；若 x != y，較輕的消失，較重的留下重量 y - x。重複直到最多只剩一顆，回傳最後重量；若全部消失則回傳 0。

## 範例

1. stones = [2,7,4,1,8,1] → 1
2. stones = [1] → 1

## 限制

- 1 <= stones.length <= 30
- 1 <= stones[i] <= 1000

## 解題思路

1. 每回合用排序找出最重的兩顆石頭。
2. 若重量相同，兩顆都移除；若不同，移除兩顆並把差值放回陣列。
3. 陣列剩下一顆時回傳它；沒有石頭時回傳 0。

## 複雜度

- 時間：O(n² log n)（每回合排序，最多進行 n - 1 回合）
- 空間：O(log n)（排序呼叫堆疊；不計輸入陣列）

## C 函式簽名

~~~c
int lastStoneWeight(int* stones, int stonesSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
