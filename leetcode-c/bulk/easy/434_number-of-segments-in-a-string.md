# 434 Number of Segments in a String：字串中的片段數

**難度：** Easy

## 題意完整翻譯

給定字串 s，回傳其中片段（segment）的數量。片段是連續的一段非空格字元；字串只用普通空格分隔片段，空字串的片段數為 0。

## 範例

### 範例 1

- 輸入：s = "Hello, my name is John"
- 輸出：5
- 說明：片段依序為 Hello,、my、name、is、John，共 5 段。

### 範例 2

- 輸入：s = "Hello"
- 輸出：1
- 說明：整個字串是一段。

## 限制

- 0 <= s.length <= 300
- s 由英文字母、數字、指定標點符號與普通空格組成
- s 中唯一的空白字元是普通空格

## 解題思路

1. 從左到右掃描字串。
2. 當前字元不是空格，而前一個位置是字串開頭或空格時，代表一個新片段開始，計數加 1。
3. 掃描結束後回傳計數。

## 複雜度

- 時間：O(n)，掃描字串一次。
- 空間：O(1)，只使用計數與索引。

## C 函式簽名

~~~c
int countSegments(char* s);
~~~

## 程式如何運作

~~~c
int countSegments(char* s) {
    int count = 0;
    int i;

    for (i = 0; s[i] != '\0'; ++i) {
        // 非空格字元若位於開頭或空格後方，就是一段的起點。
        if (s[i] != ' ' && (i == 0 || s[i - 1] == ' ')) {
            ++count;
        }
    }

    return count;
}
~~~
