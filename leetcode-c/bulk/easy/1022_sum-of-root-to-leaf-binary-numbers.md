# LeetCode 1022. Sum of Root to Leaf Binary Numbers

**難度：Easy**

## 題意完整翻譯

給定一棵二元樹，每個節點的值都是 0 或 1。從根節點走到任一葉節點會形成一個二進位數，根是最高位、葉是最低位。請把所有根到葉路徑代表的數字相加並回傳。

## 範例

1. root = [1,0,1,0,1,0,1] → 22（路徑為 100₂、101₂、110₂、111₂，即 4 + 5 + 6 + 7）
2. root = [0] → 0

## 限制

- 1 <= 節點數 <= 1000
- 每個節點值為 0 或 1
- 答案保證可用 32 位元有號整數表示

## 解題思路

1. 從根節點開始做深度優先搜尋，並帶著目前已組成的數值 prefix。
2. 走到節點 val 時，將數值更新成 prefix × 2 + val，等同於在二進位數尾端附加一位。
3. 遇到葉節點就回傳這條路徑的數值；否則遞迴計算左右子樹並將結果相加。

## 複雜度

- 時間：O(n)，每個節點走訪一次
- 空間：O(h)，遞迴堆疊高度 h；最壞 O(n)

## C 函式簽名

~~~c
int sumRootToLeaf(struct TreeNode* root);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
