# LeetCode 1128. Number of Equivalent Domino Pairs

**難度：Easy**

## 題意完整翻譯

每張骨牌以 [a,b] 表示。若兩張骨牌的兩個數字相同，且允許把其中一張翻面（[a,b] 與 [b,a] 視為相同），就稱它們等價。請計算所有索引組合 i < j 中，有多少對骨牌彼此等價。

## 範例

1. dominoes = [[1,2],[2,1],[3,4],[5,6]] → 1
2. dominoes = [[1,2],[1,2],[1,1],[1,2],[2,2]] → 3

## 限制

- 1 <= dominoes.length <= 4 × 10⁴
- 每張骨牌恰有兩個數字
- 1 <= dominoes[i][j] <= 9

## 解題思路

1. 把每張骨牌的兩個數字整理成小的在前、大的在後，這樣旋轉前後會得到同一組表示。
2. 用固定計數表記錄每種表示先前出現幾次。
3. 遇到新骨牌時，將相同表示先前的數量加到答案，再把該表示的計數加一。

## 複雜度

- 時間：O(n)
- 空間：O(1)（固定大小的計數表）

## C 函式簽名

~~~c
int numEquivDominoPairs(int** dominoes, int dominoesSize, int* dominoesColSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
