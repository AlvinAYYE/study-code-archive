# LeetCode 1005. Maximize Sum of Array After K Negations

**難度：Easy**

## 題意完整翻譯

給定整數陣列 nums 和整數 k。每次操作可選擇一個索引，將該位置的數乘以 -1；同一個索引可以重複選。恰好操作 k 次後，回傳可能得到的最大陣列總和。

## 範例

1. nums = [4,2,3], k = 1 → 5（把 2 乘以 -1，陣列變成 [4,-2,3]，總和為 5）
2. nums = [3,-1,0,2], k = 3 → 6
3. nums = [2,-3,-1,5,-4], k = 2 → 13

## 限制

- 1 <= nums.length <= 10⁴
- -100 <= nums[i] <= 100
- 1 <= k <= 10⁴

## 解題思路

1. 先把陣列由小到大排序，讓最負的數排在前面。
2. 只要還有操作次數，就依序把負數變成正數；翻轉負數會增加總和。
3. 若剩下奇數次操作，必須再翻轉一次；此時翻轉絕對值最小的數，總和損失最少。若最小值是 0，總和不變。
4. 加總陣列並回傳。

## 複雜度

- 時間：O(n log n)
- 空間：O(log n)（排序所需的呼叫堆疊；不計輸入陣列）

## C 函式簽名

~~~c
int largestSumAfterKNegations(int* nums, int numsSize, int k);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
