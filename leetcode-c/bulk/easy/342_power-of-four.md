# 342 Power of Four：4 的次方

**難度：** Easy

## 題意完整翻譯

給定整數 n，若存在整數 x 使 n = 4^x，則 n 是 4 的次方，回傳 true；否則回傳 false。指數 x 可以是 0，因此 1 也算 4 的次方。

## 範例

### 範例 1

- 輸入：n = 16
- 輸出：true
- 說明：16 = 4^2。

### 範例 2

- 輸入：n = 5
- 輸出：false
- 說明：5 不是 4 的整數次方。

### 範例 3

- 輸入：n = 1
- 輸出：true
- 說明：1 = 4^0。

## 限制

- -2^31 <= n <= 2^31 - 1

## 解題思路

1. 4 的次方必須是正數，因此 n <= 0 時直接回傳 false。
2. 只要 n 能被 4 整除，就把 n 除以 4。
3. 若最後剩下 1，n 原本就是 4 的某個次方；例如 8 除以 4 後剩 2，因此不符合。

## 複雜度

- 時間：O(log_4 n)，每次迴圈都將 n 除以 4。
- 空間：O(1)。

## C 函式簽名

~~~c
bool isPowerOfFour(int n);
~~~

## 程式如何運作

~~~c
bool isPowerOfFour(int n) {
    if (n <= 0) {
        return false;
    }

    // 4 的各次方反覆除以 4 後會恰好剩下 1。
    while (n % 4 == 0) {
        n /= 4;
    }

    return n == 1;
}
~~~
