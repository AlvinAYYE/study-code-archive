# LeetCode 1021. Remove Outermost Parentheses

**難度：Easy**

## 題意完整翻譯

有效括號字串可拆成一個或多個最外層不可再拆的有效括號片段（原始片段）。對每個片段各自移除最外面的那一對括號，再將剩下內容依原順序串接並回傳。

## 範例

1. s = "(()())(())" → "()()()"
2. s = "(()())(())(()(()))" → "()()()()(())"
3. s = "()()" → ""

## 限制

- 1 <= s.length <= 10⁵
- s[i] 只會是 '(' 或 ')'
- 輸入保證是有效括號字串

## 解題思路

1. 用 depth 記錄讀到目前位置時，括號內層的深度。
2. 遇到左括號時，若進入前 depth 大於 0，表示它不是該原始片段的最外層左括號，便加入答案；接著 depth 加一。
3. 遇到右括號時，先將 depth 減一；若減完仍大於 0，表示它不是最外層右括號，便加入答案。
4. 答案最長不會超過輸入長度，因此配置 len + 1 的空間並補上字串結尾。

## 複雜度

- 時間：O(n)
- 空間：O(n)（回傳字串）

## C 函式簽名

~~~c
char* removeOuterParentheses(char* s);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
