# LeetCode 1089. Duplicate Zeros

**難度：Easy**

## 題意完整翻譯

給定固定長度的整數陣列 arr。每遇到一個 0，就在它後面再插入一個 0，並把後續元素往右移。超出原陣列長度的元素不寫入。請直接修改輸入陣列，不回傳陣列。

## 範例

1. arr = [1,0,2,3,0,4,5,0] → 修改為 [1,0,0,2,3,0,0,4]
2. arr = [1,2,3] → 修改為 [1,2,3]

## 限制

- 1 <= arr.length <= 10⁴
- 0 <= arr[i] <= 9

## 解題思路

1. 複製原陣列，讓讀取資料不會被後續寫入覆蓋。
2. 由左至右讀取副本，將每個值寫回 arr。
3. 若讀到 0，且陣列尚有空位，再多寫一個 0；寫到陣列末端就停止。

## 複雜度

- 時間：O(n)
- 空間：O(n)（暫存副本）

## C 函式簽名

~~~c
void duplicateZeros(int* arr, int arrSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
