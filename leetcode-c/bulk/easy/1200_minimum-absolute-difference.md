# LeetCode 1200. Minimum Absolute Difference

**難度：Easy**

## 題意完整翻譯

給定整數陣列 arr，請找出所有數值差最小的元素配對。每一對以 [較小值, 較大值] 表示，並依照第一個值由小到大回傳。陣列中可能有重複數字。

## 範例

1. arr = [4,2,1,3] → [[1,2],[2,3],[3,4]]（最小差為 1）
2. arr = [1,3,6,10,15] → [[1,3]]
3. arr = [3,8,-10,23,19,-4,-14,27] → [[-14,-10],[19,23],[23,27]]

## 限制

- 2 <= arr.length <= 10⁵
- -10⁶ <= arr[i] <= 10⁶

## 解題思路

1. 先將 arr 由小到大排序。
2. 排序後，最小差值一定出現在相鄰元素之間；掃描一次找出最小差。
3. 再掃描一次，將差值等於最小差的相鄰配對依序放入回傳陣列。

## 複雜度

- 時間：O(n log n)
- 空間：O(k + log n)，k 是回傳的配對數（含排序堆疊）

## C 函式簽名

~~~c
int** minimumAbsDifference(int* arr, int arrSize, int* returnSize, int** returnColumnSizes);
~~~

## 程式如何運作
