# LeetCode 1175. Prime Arrangements

**難度：Easy**

## 題意完整翻譯

計算 1 到 n 的數字排列數量，使所有質數都放在質數編號的位置上（位置從 1 開始編號）。例如，位置 2、3、5 是質數位置。答案可能很大，請回傳它除以 1,000,000,007 的餘數。質數是大於 1 且不能寫成兩個比它小的正整數相乘的數。

## 範例

1. n = 5 → 12（有 3 個質數，可在質數位置互換排列 3! 種；其餘 2 個數字可排列 2! 種，所以共 3! × 2! = 12）
2. n = 100 → 682289015

## 限制

- 1 <= n <= 100

## 解題思路

1. 逐一檢查 2 到 n 的數字，統計質數個數 p。
2. 質數要放進 p 個質數位置，可排列 p! 種；其餘 n-p 個數字放進剩下位置，可排列 (n-p)! 種。
3. 將兩個階乘相乘，計算過程每次都對 1,000,000,007 取餘數，避免數值過大。

## 複雜度

- 時間：O(n√n)（檢查質數；階乘計算 O(n)）
- 空間：O(1)

## C 函式簽名

~~~c
int numPrimeArrangements(int n);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
