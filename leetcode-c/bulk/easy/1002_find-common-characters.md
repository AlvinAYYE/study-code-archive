# LeetCode 1002. Find Common Characters

**難度：Easy**

## 題意完整翻譯

給定一組只含小寫英文字母的字串，找出每個字串都共同包含的字母，並保留重複次數。答案可用任何順序回傳。例如，每個字串各有兩個 l，答案也要有兩個 l。

## 範例

1. words = ["bella","label","roller"] → ["e","l","l"]
2. words = ["cool","lock","cook"] → ["c","o"]

## 限制

- 1 <= words.length <= 100
- 1 <= words[i].length <= 100
- words[i] 只含小寫英文字母

## 解題思路

1. 先統計第一個字串中 a 到 z 各出現幾次，作為目前的共同上限。
2. 逐一統計其他字串的 26 種字母次數，對每個字母保留目前上限和本字串次數中較小的值。
3. 依照最後的共同次數配置字串陣列；某字母共同出現幾次，就放入幾個該字母。

## 複雜度

- 時間：O(字串總長度 + 26 × 字串數)
- 空間：O(1) 額外空間（26 個字母計數器；另需 O(輸出大小) 回傳資料）

## C 函式簽名

~~~c
char** commonChars(char** words, int wordsSize, int* returnSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
