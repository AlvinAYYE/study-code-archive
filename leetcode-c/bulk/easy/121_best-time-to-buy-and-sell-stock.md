# LeetCode 121. Best Time to Buy and Sell Stock

**難度：Easy**

## 題意完整翻譯

給定 prices[i]，表示第 i 天的股票價格。你最多只能完成一次交易：先買進一股，再於之後某一天賣出。請回傳能得到的最大利潤；若無法獲利，回傳 0。

## 範例

1. prices = [7,1,5,3,6,4] → 5（第 2 天以 1 買進，第 5 天以 6 賣出，利潤 6 - 1 = 5）
2. prices = [7,6,4,3,1] → 0（價格一路下跌，不交易）

## 限制

- 1 <= prices.length <= 10⁵
- 0 <= prices[i] <= 10⁴

## 解題思路

1. 從左到右掃描價格，記錄目前看過的最低價格，作為可能的買進價。
2. 對每一天，計算當天價格減去最低買進價，更新最大利潤。
3. 再用當天價格更新最低價，確保日後的買進發生在賣出之前。

## 複雜度

- 時間：O(n)
- 空間：O(1)

## C 函式簽名

~~~c
int maxProfit(int* prices, int pricesSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
