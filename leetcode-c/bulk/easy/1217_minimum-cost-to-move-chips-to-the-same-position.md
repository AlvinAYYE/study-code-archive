# LeetCode 1217. Minimum Cost to Move Chips to The Same Position

**難度：Easy**

## 題意完整翻譯

給定每個晶片所在的位置。每次可以把一個晶片移動 2 格，成本為 0；或移動 1 格，成本為 1。請找出讓所有晶片移到同一位置所需的最小總成本。

## 範例

1. position = [1,2,3] → 1
2. position = [2,2,2,3,3] → 2
3. position = [1,1000000000] → 1

## 限制

- 1 <= position.length <= 100
- 1 <= position[i] <= 10⁹

## 解題思路

1. 移動 2 格不花成本，因此奇數位置的晶片可以免費移到任意奇數位置，偶數位置也能免費互相移動。
2. 要集中到偶數位置，就必須把所有奇數位置晶片各移 1 格；集中到奇數位置則要移動所有偶數位置晶片。
3. 統計奇數與偶數位置晶片數量，選較少的一邊支付成本。

## 複雜度

- 時間：O(n)
- 空間：O(1)

## C 函式簽名

~~~c
int minCostToMoveChips(int* position, int positionSize);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
