# 0013. Roman to Integer《羅馬數字轉整數》

- **難度**：Easy
- **標籤**：hash-table、math、string
- **題目連結**：https://leetcode.com/problems/roman-to-integer/
- **程式碼**：[`013_roman-to-integer.c`](./013_roman-to-integer.c)

## 題目說明

羅馬數字使用 `I`、`V`、`X`、`L`、`C`、`D`、`M`，分別代表 1、5、10、50、100、500、1000。通常符號由大到小排列並相加；較小符號放在較大符號左邊時表示相減。合法減法組合為 `IV`、`IX`、`XL`、`XC`、`CD`、`CM`。給定一個合法羅馬數字字串 `s`，將它轉換成整數。

## 範例

```text
輸入：s = "III"
輸出：3
說明：III = 1 + 1 + 1。

輸入：s = "LVIII"
輸出：58
說明：L + V + III = 50 + 5 + 3。

輸入：s = "MCMXCIV"
輸出：1994
說明：M + CM + XC + IV = 1000 + 900 + 90 + 4。
```

## 限制

- `1 <= s.length <= 15`
- `s` 只包含 `I`、`V`、`X`、`L`、`C`、`D`、`M`。
- `s` 保證是 `[1, 3999]` 範圍內的合法羅馬數字。

## 直觀解題思路

1. 將每個羅馬符號映射成對應整數，由左至右累加。
2. 若目前值大於前一值，表示前一符號屬於減法組合。
3. 前一值已經加過一次，所以再扣除兩倍前一值，就能把原本的 `+prev` 改成 `-prev`。

- 時間複雜度：`O(n)`
- 額外空間複雜度：`O(1)`

## 官方 C 函式簽名

```c
int romanToInt(char* s);
```
