# LeetCode 222. Count Complete Tree Nodes

**難度：Easy**

## 題意完整翻譯

給定一棵完全二元樹的根節點 root，請回傳樹中的節點總數。完全二元樹除了最後一層外都填滿；最後一層的節點從左側開始連續排列。

## 範例

1. root = [1,2,3,4,5,6] → 6
2. root = [] → 0
3. root = [1] → 1

## 限制

- 節點數介於 0 到 5 × 10⁴
- 0 <= Node.val <= 5 × 10⁴
- 輸入保證是完全二元樹

## 解題思路

1. 若目前節點是空指標，這棵子樹有 0 個節點。
2. 否則目前節點本身算 1 個，再遞迴計算左子樹與右子樹。
3. 將三部分相加並回傳。

## 複雜度

- 時間：O(n)，每個節點走訪一次
- 空間：O(h) 遞迴堆疊，h 為樹高

## C 函式簽名

~~~c
int countNodes(struct TreeNode* root);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式註解標出每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
