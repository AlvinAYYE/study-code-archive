# LeetCode 1047. Remove All Adjacent Duplicates in String

**難度：Easy**

## 題意完整翻譯

給定只含小寫英文字母的字串 s。一次移除操作是刪掉一對相鄰且相同的字母。請不斷移除直到字串中沒有這種相鄰字母對，回傳最後結果；題目保證結果唯一。

## 範例

1. s = "abbaca" → "ca"（先刪 bb，再刪 aa）
2. s = "azxxzy" → "ay"（刪除 xx 後，新形成的 xx 也會被刪除）

## 限制

- 1 <= s.length <= 10⁵
- s[i] 只含小寫英文字母

## 解題思路

1. 把輸入字串前段當作堆疊，top 表示目前結果的長度。
2. 逐字讀取 s：若新字母和堆疊頂端相同，就把頂端移除；否則把新字母推入堆疊。
3. 被移除後的新頂端會自然與下一個字母比較，因此也能處理連鎖消除。
4. 最後在堆疊尾端補上字串結尾符號並回傳原字串。

## 複雜度

- 時間：O(n)
- 空間：O(1) 額外空間（直接把輸入字串當作堆疊使用）

## C 函式簽名

~~~c
char* removeDuplicates(char* s);
~~~

## 程式如何運作

提交函式依照上述步驟完成計算；程式中的註解對應每個關鍵動作。本地測試 harness 保留在 .c 檔尾端。
