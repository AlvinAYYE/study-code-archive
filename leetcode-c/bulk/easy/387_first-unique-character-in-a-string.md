# 387 First Unique Character in a String：字串中的第一個唯一字元

**難度：** Easy

## 題意完整翻譯

給定只含小寫英文字母的字串 s，找出第一個只出現一次的字元，並回傳它在字串中的索引。若沒有這種字元，回傳 -1。索引從 0 開始。

## 範例

### 範例 1

- 輸入：s = "leetcode"
- 輸出：0
- 說明：l 只出現一次，且它是最左邊的唯一字元。

### 範例 2

- 輸入：s = "loveleetcode"
- 輸出：2
- 說明：索引 2 的 v 是第一個只出現一次的字元。

### 範例 3

- 輸入：s = "aabb"
- 輸出：-1
- 說明：a 與 b 都出現兩次，沒有唯一字元。

## 限制

- 1 <= s.length <= 10^5
- s 只含小寫英文字母

## 解題思路

1. 第一次掃描字串，統計 26 個字母各自出現的次數。
2. 第二次由左向右掃描，第一個計數為 1 的位置就是答案。
3. 若掃描完都沒有計數為 1 的字母，回傳 -1。

## 複雜度

- 時間：O(n)，最多掃描字串兩次。
- 空間：O(1)，只使用 26 個計數欄位。

## C 函式簽名

~~~c
int firstUniqChar(char* s);
~~~

## 程式如何運作

~~~c
int firstUniqChar(char* s) {
    int frequency[26] = {0};
    int i;

    // 第一遍統計每個字母出現幾次。
    for (i = 0; s[i] != '\0'; ++i) {
        ++frequency[s[i] - 'a'];
    }

    // 第二遍找到最早只出現一次的字母。
    for (i = 0; s[i] != '\0'; ++i) {
        if (frequency[s[i] - 'a'] == 1) {
            return i;
        }
    }

    return -1;
}
~~~
