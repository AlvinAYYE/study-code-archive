# 演算法題目搜尋索引

依題名、競賽年度、演算法、用途或中英文別名查找。此索引為純 Markdown，可離線閱讀。

## 使用方式

- 在此頁按 `Ctrl+F`，搜尋中文題名、英文名、縮寫或關鍵字。
- 在 VS Code 開啟整個資料夾後按 `Ctrl+Shift+F`，可搜尋題目說明與程式碼內容。
- 點「程式碼」直達對應 C 範例；解題概念與應用可查看[題目清單與來源](<題目清單與來源.md>)。
- 可用多個關鍵字縮小範圍，例如 `111 BFS`、`最短路徑 Dijkstra`、`影像卷積`。
