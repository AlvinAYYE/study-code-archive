# 地區設定

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<locale.h>`

setlocale
|   | 查詢或設定目前的 C 地區設定（locale）
(function)   |

localeconv
|   | 查詢目前地區設定中的數字與貨幣格式規則
(function)   |

lconv
|   | 儲存 `localeconv` 傳回的格式規則
(struct)  |

#####  Locale categories

LC_ALLLC_COLLATELC_CTYPELC_MONETARYLC_NUMERICLC_TIME
|   | `setlocale` 可設定的地區設定類別
(macro constant)   |
