# isgraph

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<ctype.h>`
|   |  |   |  |

```c
int isgraph( int ch );
```
|   |   |   |   |

|  |  |  |  |

Checks if the given character has a graphical representation, i.e. it is either a number (`0123456789`), an uppercase letter (`ABCDEFGHIJKLMNOPQRSTUVWXYZ`), a lowercase letter (`abcdefghijklmnopqrstuvwxyz`), or a punctuation character (`!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~`), or any graphical character specific to the current C locale.
檢查字元 ch 是否為可見字元（不含空格）。在預設 C 地區設定中，數字、英文字母和標點符號都符合；其他地區設定也可能包含額外的可見字元。
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to `EOF`.
若 ch 的值無法由 unsigned char 表示，且也不等於 EOF，行為未定義。

### Parameters

| ch  |   | -  |   | character to classify  |

### Return value

Non-zero value if the character has a graphical representation character, zero otherwise.
如果字元具有圖形表示字元則傳回非零值，否則傳回零。

### Example

Run this code

```c
#include <ctype.h> #include <locale.h> #include <stdio.h>   int main(void) {  unsigned char c = '\xb6'; // the character ¶ in ISO-8859-1  printf("In the default C locale, \\xb6 is %sgraphical\n",  isgraph(c) ? "" : "not " );  setlocale(LC_ALL, "en_GB.iso88591");  printf("In ISO-8859-1 locale, \\xb6 is %sgraphical\n",  isgraph(c) ? "" : "not " ); }
```

Possible output:
可能的輸出：

```c
In the default C locale, \xb6 is not graphical In ISO-8859-1 locale, \xb6 is graphical
```
