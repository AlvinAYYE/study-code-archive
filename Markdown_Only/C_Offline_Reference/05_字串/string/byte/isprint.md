# isprint

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<ctype.h>`
|   |  |   |  |

```c
int isprint( int ch );
```
|   |   |   |   |

|  |  |  |  |

Checks if the given character can be printed, i.e. it is either a number (`0123456789`), an uppercase letter (`ABCDEFGHIJKLMNOPQRSTUVWXYZ`), a lowercase letter (`abcdefghijklmnopqrstuvwxyz`), a punctuation character (`!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~`), or space, or any character classified as printable by the current C locale.
檢查字元 ch 是否為可列印字元。在預設 C 地區設定中，數字、英文字母、標點符號和空格都可列印；其他地區設定也可能包含額外的可列印字元。
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to `EOF`.
若 ch 的值無法由 unsigned char 表示，且也不等於 EOF，行為未定義。

### Parameters

| ch  |   | -  |   | character to classify  |

### Return value

Non-zero value if the character can be printed, zero otherwise.
如果該字元可列印則傳回非零值，否則傳回 0。

### Example

Run this code

```c
#include <ctype.h> #include <locale.h> #include <stdio.h> int main(void) {  unsigned char c = '\xa0'; // the non-breaking space in ISO-8859-1  printf("In the default C locale, \\xa0 is %sprintable\n", isprint(c)?"":"not ");  setlocale(LC_ALL, "en_GB.iso88591");  printf("In ISO-8859-1 locale, \\xa0 is %sprintable\n", isprint(c)?"":"not "); }
```

Possible output:
可能的輸出：

```c
In the default C locale, \xa0 is not printable In ISO-8859-1 locale, \xa0 is printable
```
