# C keywords: _Noreturn (since C11)(deprecated in C23)

> 來源：cppreference C 語言參考文件（離線轉換版）。

### Usage

-  `_Noreturn` function specifier (deprecated in C23)
_Noreturn 函式說明符（在 C23 中已棄用）

-  `_Noreturn` attribute-token (since C23)(deprecated in C23)
_Noreturn 屬性記號（自 C23 起）（在 C23 中已棄用）

### Notes

Since C23, `_Noreturn` is also attribute token. Its usage is deprecated and `noreturn` should be used instead.
自 C23 起，_Noreturn 也是屬性記號（attribute token）。它的用法已被棄用，應改用 noreturn 。
