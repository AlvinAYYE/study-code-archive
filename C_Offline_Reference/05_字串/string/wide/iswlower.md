# iswlower

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<wctype.h>`
|   |  |   |  |

```c
int iswlower( wint_t ch );
```
|   |   |   |  (since C95)  |

|  |  |  |  |

Checks if the given wide character is a lowercase letter, i.e. one of `abcdefghijklmnopqrstuvwxyz` or any lowercase letter specific to the current locale.
檢查給定的寬字元是否為小寫字母，即 abcdefghijklmnopqrstuvwxyz 之一或目前本地化環境特有的任何小寫字母。

### Parameters

| ch  |   | -  |   | wide character  |

### Return value

Non-zero value if the wide character is an lowercase letter, zero otherwise.
如果寬字元是小寫字母則傳回非零值，否則傳回零。

### Notes

ISO 30112 specifies which Unicode characters are include in POSIX lower category.
ISO 30112 規定了哪些 Unicode 字元包含在 POSIX lower 類別中。

### Example

Run this code

```c
#include <locale.h> #include <stdio.h> #include <wchar.h> #include <wctype.h> int main(void) {  wchar_t c = L'\u0444'; // Cyrillic small letter ef ('ф')  printf("In the default locale, iswlower(%#x) = %d\n", c, !!iswlower(c));  setlocale(LC_ALL, "en_US.utf8");  printf("In Unicode locale, iswlower(%#x) = %d\n", c, !!iswlower(c)); }
```

Output:

```c
In the default locale, iswlower(0x444) = 0 In Unicode locale, iswlower(0x444) = 1
```
