# iswspace

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<wctype.h>`
|   |  |   |  |

```c
int iswspace( wint_t ch );
```
|   |   |   |  (since C95)  |

|  |  |  |  |

Checks if the given wide character is a whitespace character, i.e. either space (`0x20`), form feed (`0x0c`), line feed (`0x0a`), carriage return (`0x0d`), horizontal tab (`0x09`), vertical tab (`0x0b`) or any whitespace character specific to the current locale.
檢查給定的寬字元是否為空白字元，即空格（ 0x20 ）、換頁（ 0x0c ）、換行（ 0x0a ）、回車（ 0x0d ）、水平製表（ 0x09 ）、垂直製表（ 0x0b ）或目前本地化環境特有的任何空白字元。

### Parameters

| ch  |   | -  |   | wide character  |

### Return value

Non-zero value if the wide character is a whitespace character, zero otherwise.
如果寬字元是空白字元則傳回非零值，否則傳回零。

### Notes

ISO 30112 defines POSIX space characters as Unicode characters U+0009..U+000D, U+0020, U+1680, U+180E, U+2000..U+2006, U+2008..U+200A, U+2028, U+2029, U+205F, and U+3000.
ISO 30112 將 POSIX 空格字元定義為 Unicode 字元 U+0009..U+000D、U+0020、U+1680、U+180E、U+2000..U+2006、U+2008..U+200A、U+2028、U+2029、U+205F 和 U+3000。

### Example

Run this code

```c
#include <locale.h> #include <stdio.h> #include <wchar.h> #include <wctype.h> int main(void) {  wchar_t c = L'\u2003'; // Unicode character 'EM SPACE'  printf("In the default locale, iswspace(%#x) = %d\n", c, !!iswspace(c));  setlocale(LC_ALL, "en_US.utf8");  printf("In Unicode locale, iswspace(%#x) = %d\n", c, !!iswspace(c)); }
```

Output:

```c
In the default locale, iswspace(0x2003) = 0 In Unicode locale, iswspace(0x2003) = 1
```
