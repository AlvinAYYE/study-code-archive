# iswblank

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<wctype.h>`
|   |  |   |  |

```c
int iswblank( wint_t ch );
```
|   |   |   |  (since C99)  |

|  |  |  |  |

Checks if the given wide character is classified as blank character (that is, a whitespace character used to separate words in a sentence) by the current C locale. In the default C locale, only space (`0x20`) and horizontal tab (`0x09`) are blank characters.
檢查給定的寬字元是否被目前 C 本地化環境分類為空白字元（即用於分隔句子中單詞的空白字元）。在預設 C 本地化環境中，只有空格（ 0x20 ）和水平製表符（ 0x09 ）是空白字元。

### Parameters

| ch  |   | -  |   | wide character  |

### Return value

Non-zero value if the wide character is a blank character, zero otherwise.
如果寬字元是空白字元則傳回非零值，否則傳回零。

### Notes

ISO 30112 defines POSIX blank characters as Unicode characters U+0009, U+0020, U+1680, U+180E, U+2000..U+2006, U+2008, U+200A, U+205F, and U+3000.
ISO 30112 將 POSIX 空白字元定義為 Unicode 字元 U+0009、U+0020、U+1680、U+180E、U+2000..U+2006、U+2008、U+200A、U+205F 和 U+3000。

### Example

Run this code

```c
#include <locale.h> #include <stdio.h> #include <wchar.h> #include <wctype.h> int main(void) {  wchar_t c = L'\u3000'; // Ideographic space ('　')  printf("In the default locale, iswblank(%#x) = %d\n", c, !!iswblank(c));  setlocale(LC_ALL, "en_US.utf8");  printf("In Unicode locale, iswblank(%#x) = %d\n", c, !!iswblank(c)); }
```

Output:

```c
In the default locale, iswblank(0x3000) = 0 In Unicode locale, iswblank(0x3000) = 1
```
