# isblank

> 來源：cppreference C 語言參考文件（離線轉換版）。

Defined in header `<ctype.h>`
|   |  |   |  |

```c
int isblank( int ch );
```
|   |   |   |  (since C99)  |

|  |  |  |  |

Checks if the given character is a blank character in the current C locale. In the default C locale, only space (`0x20`) and horizontal tab (`0x09`) are classified as blank.
檢查字元 ch 是否為目前 C 地區設定中的空格或定位字元。在預設的 C 地區設定中，只有空格（0x20）和水平定位字元（0x09）符合。
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to `EOF`.
若 ch 的值無法由 unsigned char 表示，且也不等於 EOF，行為未定義。

### Parameters

| ch  |   | -  |   | character to classify  |

### Return value

Non-zero value if the character is a blank character, zero otherwise.
如果字元是空白字元則傳回非零值，否則傳回零。

### Example

Run this code

```c
#include <ctype.h> #include <limits.h> #include <stdio.h> int main(void) {  for (int ndx = 0; ndx != UCHAR_MAX; ++ndx)  if (isblank(ndx))  printf("0x%02x\n", ndx); }
```

Output:

```c
0x09 0x20
```
