# C keywords: default

> 來源：cppreference C 語言參考文件（離線轉換版）。

### Usage

-  `switch` statement: as the declaration of the default case label
switch 陳述式：作為 default case 標籤的宣告

-  type-generic expression: as the declaration of the default generic association
