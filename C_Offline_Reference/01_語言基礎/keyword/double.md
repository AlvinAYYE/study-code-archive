# C keywords: double

> 來源：cppreference C 語言參考文件（離線轉換版）。

### Usage

-  `double` type: as the declaration of the type
double 型別：作為該型別的宣告

-  `long double` type: as the declaration of the type when combined with long
long double 型別：作為與 long 組合時該型別的宣告
