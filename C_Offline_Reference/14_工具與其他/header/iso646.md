# Standard library header <iso646.h> (C95)

> 來源：cppreference C 語言參考文件（離線轉換版）。

This header defines macros for alternative operator spellings.
該標頭檔為運運算元的替代拼寫定義宏。

### Synopsis

```c
#define and && #define and_eq &= #define bitand & #define bitor | #define compl ~ #define not  ! #define not_eq  != #define or || #define or_eq |= #define xor ^ #define xor_eq ^=
```

### Notes

This header is meaningless in C++ because these macro names exist as keywords in C++ and are unconditionally available.
這個標頭檔在 C++ 中沒有用途，因為這些巨集名稱在 C++ 中是關鍵字，而且不需額外宣告即可使用。
