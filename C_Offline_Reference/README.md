# C 語言離線參考資料

這是從 Zeal 的 C 文件轉成的 Markdown 文件集，供離線閱讀與查找。文件正文保留 cppreference 原文；部分頁面含原有繁體中文翻譯。資料夾名稱、使用說明與索引採中文。

## 快速查找

- 開啟 `函式/README.md` 查標準函式；`型別/README.md` 查型別與結構。
- `巨集與常數/README.md`、`關鍵字/README.md`、`指南與標頭檔/README.md` 收錄其他項目。
- 依主題瀏覽資料夾，例如 `04_輸入輸出`、`05_字串`、`03_記憶體`。
- 在支援 Markdown 的文字檢視器中用搜尋功能查符號。檔案均為 `.md`，本資料夾不含 HTML、程式或執行檔。
