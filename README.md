# 程式設計題庫與演算法練習

這個儲存庫彙整 LeetCode、UVa、演算法競賽、C 語言課程與舊比賽程式。要找題目，先開啟 [題目目錄](題目目錄.md)。目錄以「英文題目名、英文描述、中文題目名、中文詳細描述、涵蓋的演算法範圍、檔案位置」六欄列出已有 C 原始碼的題目，檔案位置可直接點開原始碼。

## 快速查找

1. 在[題目目錄](題目目錄.md)按 `Ctrl+F`，輸入題號、中文或英文題名、題意關鍵字，或 `Dynamic Programming`、`BFS`、`Sorting` 等演算法名。
2. 點「檔案位置」開啟程式。演算法競賽、歷屆題目、範例與複習題會列出對應的 C、C#、VB 程式路徑；LeetCode 同題若有精選與批量兩份解答，目錄優先連到精選版。
3. 若要找尚未有 C 解答的 LeetCode 題面，使用[完整題庫索引](leetcode-c/DB_INDEX.tsv)，再依題號與 slug 開啟 `leetcode-c/problems/` 中的 JSON。

| 題庫 | 其他入口 |
|---|---|
| LeetCode C 解答 | [題庫說明](leetcode-c/README.md)、[精選索引](leetcode-c/INDEX.md)、[批量索引](leetcode-c/BULK_INDEX.tsv) |
| UVa C 解答 | [題庫說明](UVa-c/README.md) |
| 演算法競賽、歷屆題目、範例與複習 | [搜尋索引](演算法題目整理/搜尋索引.md)、[題目概念清單](演算法題目整理/題目清單與來源.md) |
| 115 學年 C 課程練習 | [課程題目資料夾](115_C_class/) |
| 以前比賽的程式 | [比賽程式資料夾](以前比賽的code/) |

各題庫的目前題數見[題目目錄](題目目錄.md)的章節標題。LeetCode 完整 JSON 題庫另收錄約 2,913 道題面，不代表每題都有解答。原始資料中的部分中文欄位只有中英混合摘要或尚缺正式中文題名；目錄會明確標示，並保留原始檔連結供核對。

## 更新題目目錄

新增或調整題目後，在儲存庫根目錄執行：

```powershell
python tools/build_problem_catalog.py
```

產生器會讀取現有索引、題目資料與原始碼註解，更新[題目目錄](題目目錄.md)。若新增的是 LeetCode 解答，請先更新對應的 `INDEX.tsv` 或 `BULK_INDEX.tsv`；演算法題庫請先更新 `演算法題目整理/搜尋索引.md`。
