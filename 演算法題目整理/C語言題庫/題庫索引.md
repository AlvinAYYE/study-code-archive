# C 語言演算法題庫

共 32 題／範例；每題一個資料夾，內含獨立的 `main.c`。每個 C 檔開頭都有繁體中文的初學者詳細導讀，逐步說明輸入、變數、演算法與 C 語法。變數名稱依用途整理，程式統一使用四格縮排及清楚的區塊排版。程式只使用 C 標準函式庫，可離線編譯。

## Windows 使用方式

在題目資料夾開啟命令提示字元或 PowerShell（Windows 使用 UTF-8 主控台可先執行 `chcp 65001`）：

```text
gcc main.c -std=c11 -O2 -o main.exe
main.exe
```

多數程式從鍵盤標準輸入讀資料；各資料夾的 `main.c` 開頭註解列出輸入格式。「隨機實數值轉換為等效二進制值」使用數學函式，若在 Linux/GCC 編譯，指令加上 `-lm`。部分題目會在執行資料夾產生 `.pgm` 或 `.svg` 檔，SVG 可用本機瀏覽器離線開啟，PGM 可用支援 PGM 的圖片工具開啟。

## 題目敘述與假設

部分舊資料只有解答專案，缺少完整正式題目敘述；這些 C 版依現有程式碼與資料檔推定輸入格式，並採用可離線執行的命令列呈現。特別是「最小路徑程式」採右／下移動的網格最短路徑；「資料分群」採 K-means；遇到考卷原始規格時，請以考卷輸入輸出要求為準。
