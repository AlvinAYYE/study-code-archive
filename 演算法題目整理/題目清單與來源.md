# 演算法題目整理

此清單整理資料夾中找到程式碼解答的演算法與資料結構題目，著重於題目概念、解題方法及適用情境，不列原始來源路徑。

| 題目 | 註解 | 使用到的方式與情境 |
|---|---|---|
| 96 年 Q5：計算次方及餘數 | 計算次方後取餘數；指數很大時可用快速冪，避免逐次相乘。 | 模冪運算可用於密碼學、模數下的組合數計算。 |
| 104 年 Q5：2D Convolution | 二維矩陣套用滑動視窗，逐格計算鄰近資料的加權和。 | 用於影像濾鏡、影像辨識與卷積神經網路。 |
| 106 年 Q1：資料分群 | 依資料相似度或題目指定條件將資料分組；實際分群規則依題目而定。 | 用於顧客分群、文件分類與資料探索。 |
| 106 年 Q2：簡易依序循環之排程程式 | 依序輪流分配處理時間或工作，完成一輪後再從頭開始。 | 用於 Round Robin 作業排程、輪流服務與公平分配資源。 |
| 107 年 Q5：求陣列的子陣列之和的最大值 | 找出總和最大的連續子陣列；可用動態規劃或 Kadane 演算法。 | 用於連續資料區段分析，例如找出某段期間的最大累積變化。 |
| 107 年 Q6：簡易霍夫曼解碼 | 依霍夫曼碼表或二元樹，將變長編碼還原成原始符號。 | 用於解壓縮文字或其他無失真壓縮資料。 |
| 108 年 Q3：解密碼演算法 | 依題目指定的轉換規則或密鑰，將密文還原；具體規則以題目為準。 | 用於理解加密、解密與資料編碼轉換。 |
| 109 年 Q4：凸形直綫環繞系統 | 從平面點集合找出包住所有點的凸包或外框。 | 用於地圖邊界、物件碰撞範圍與地理資料外框計算。 |
| 110 年 Q3：Fibonacci Sequence | 依前兩項推算後續項目；可用迴圈或動態規劃避免重複計算。 | 用於練習數列、遞迴及動態規劃。 |
| 110 年 Q4：最小路徑程式 | 在圖或格子中找出成本最低的路徑；演算法需依邊權與題目限制選擇。 | 用於導航、網路路由與地圖路徑規劃。 |
| 111 第一次模擬賽 Q2：逆波蘭表示法計算機 | 以堆疊處理後序運算式：數字入堆疊，遇到運算子便取出運算元計算。 | 用於計算機實作、編譯器的運算式剖析。 |
| 111 第一次模擬賽 Q3：印出二元搜尋樹兩節點路徑 | 利用二元搜尋樹的大小排序性質，尋找節點與共同祖先，再輸出路徑。 | 用於樹狀索引與階層資料中的節點關係查詢。 |
| 111 第一次模擬賽 Q5：最短路徑規劃 | 將位置與連線建成圖，求兩點間總成本最小的路徑。 | 用於交通導航、網路封包路由與物流規劃。 |
| 111 第三次模擬賽 Q2：找零錢 | 將總金額拆成指定面額；依面額規則使用貪婪法或動態規劃。 | 用於收銀找零，以及計算達成金額所需的最少硬幣數。 |
| 111 第三次模擬賽 Q5：二元搜尋樹的前序表示 | 依前序走訪順序處理或重建二元搜尋樹。 | 用於樹的序列化、結構重建與走訪練習。 |
| 111 第三次模擬賽 Q6：巴斯卡三角形 | 每個內部數值由上一列相鄰兩數相加，也可用來求二項式係數。 | 用於組合數、二項式展開及動態規劃入門。 |
| 111 第四次模擬賽 Q6：最長遞增子序列 | 在不改變元素順序的條件下，找出最長的遞增子序列；常見解法為動態規劃。 | 用於序列分析、版本差異分析與動態規劃練習。 |
| 工科賽 101 年：迷宮遊戲 | 將可走位置視為圖的節點，以 DFS 或 BFS 搜尋出口或路徑。 | 用於迷宮尋路、地圖搜尋與圖形遍歷。 |
| 工科賽 102 年：多矩陣相乘運算次數 | 矩陣相乘順序不影響結果，但會改變計算量；可用區間動態規劃選擇成本最低的括號順序。 | 用於最佳化矩陣鏈的計算順序，降低運算量。 |
| 工科賽 102 年：最小成本 | 在多種選擇或路徑中找總成本最低的方案；具體解法依題目規則判斷。 | 用於資源配置、路徑成本比較與最低費用方案。 |
| 工科賽 102 年：膨脹處理 | 以結構元素擴張影像中的前景區域，屬於影像形態學處理。 | 用於連接影像中的斷裂區域、擴大物件邊界或影像前處理。 |
| 工科賽 102 年：隨機實數值轉換為等效二進制值 | 將實數轉為二進位表示，分別處理整數部分與小數部分。 | 用於浮點數表示、數值格式轉換與計算機概論。 |
| 商科賽 96 年 Problem 1：最長遞增子序列 | 與前述最長遞增子序列同類，保留原順序找出最長遞增序列。 | 用於序列分析與動態規劃練習。 |
| 生命遊戲 | 每一輪依周圍格子的狀態更新細胞生死，是細胞自動機模擬。 | 用於網格模擬、局部規則系統與複雜行為展示。 |
| 霍夫曼編碼 | 依符號出現頻率建構霍夫曼樹，讓常見符號使用較短編碼。 | 用於無失真資料壓縮。 |
| 八皇后 | 以回溯法逐列放置皇后，排除同列、同欄與同斜線衝突。 | 用於約束滿足、回溯搜尋與棋盤問題。 |
| 8-Puzzle（BFS／DFS） | 將棋盤排列視為狀態，透過移動空格產生新狀態，再搜尋目標排列。 | 用於狀態空間搜尋；BFS 可找最少步數解，DFS 可探索可達狀態。 |
| 排序演算法驗證 | 以測試資料確認排序結果，或比較不同排序法的執行表現。 | 用於檢查排序正確性、比較效率及觀察資料規模的影響。 |
| 搜尋演算法驗證 | 以測試資料確認搜尋結果，或比較線性搜尋與二分搜尋等方法。 | 用於資料查找、搜尋效率比較，以及理解二分搜尋需要資料有序。 |
| 二元樹 | 練習建立二元樹並走訪節點，例如前序、中序、後序或層序走訪。 | 用於階層資料、語法樹與索引結構。 |
| 複習：最短路徑 | 以圖表示節點與邊，再依題目條件選演算法找出最短路徑。 | 用於導航、網路路由與圖論練習。 |
| 複習：最長子序列 | 保留元素相對順序，找出符合條件的最長子序列；若條件為遞增即為 LIS。 | 用於動態規劃、序列比對與資料變化分析。 |

> 註：部分題目名稱無法單獨確定原解答採用的演算法，因此註解說明的是題目對應的常見概念；實際實作仍以題目規則與解答程式為準。
