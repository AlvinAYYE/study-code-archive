# 演算法題目整理

這份資料夾收錄歷屆競賽題目、演算法範例、複習題，以及可離線編譯的 C 語言解答。從這裡開始找題目：

- [搜尋索引](<搜尋索引.md>)：依題名、類別、年份、演算法關鍵字查找，並直達程式碼。
- [題目概念與解法清單](<題目清單與來源.md>)：依題名閱讀解題概念、常見方法與適用情境。
- [C 語言題庫索引](<C語言題庫/題庫索引.md>)：瀏覽題庫並直接開啟各題的 `main.c`。

## 快速搜尋

在 VS Code 開啟此資料夾後，按 `Ctrl+Shift+F` 搜尋整個題庫；按 `Ctrl+F` 搜尋目前的索引或程式。也可先看[搜尋索引](<搜尋索引.md>)，用中文題名、英文名稱、縮寫或演算法名定位，例如 `最短路徑`、`Dijkstra`、`LIS`、`BFS`、`卷積`、`Huffman`。

搜尋範圍可用以下路徑縮小：

| 想找 | 搜尋位置 |
|---|---|
| 題目概念、解法與應用 | `題目清單與來源.md` |
| C 題目名稱與程式 | `C語言題庫/` |
| 工科賽題 | `01 工科賽解題/` |
| 歷屆工科賽、商科賽 | `02 歷屆題目/` |
| 獨立演算法範例 | `03 其他演算法範例/` |
| 複習練習 | `04 複習練習/` |

搜尋程式碼時，可直接搜尋函式名稱、變數名或輸入輸出提示；多數 C 範例在檔案開頭附有題目說明與輸入格式。
