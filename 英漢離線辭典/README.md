# 英漢離線辭典

這是一份可離線閱讀的 Markdown 英漢詞條庫。

## 快速查字

1. 開啟[詞頭索引](索引/README.md)，選擇字母。
2. 在字母索引中點選英文詞頭，直接跳到詞條。
3. 索引只連到本資料夾內的 Markdown 文件；不含 Cambridge／Oxford 逐詞外部連結。

## 收錄範圍

- 共收錄 **95,892** 條含中文對譯的詞目；未含中文對譯的純英文釋義已略過。
- 來源詞庫共有 170,953 個詞頭。依上游資料提供度，保留詞性、音標、中文對譯、英文釋義及例句。
- 上游詞形索引未納入；查變化詞時可改查原形。
- 中文內容由簡體轉為繁體（臺灣用字轉換）。部分譯詞可能不是臺灣慣用說法，建議作閱讀查考。
- **這不是 Cambridge 或 Oxford 官方詞條，也不代表出版社背書。**未取得出版社授權前，不會把其受版權保護的詞條複製到離線文件。
- 本資料夾只包含 Markdown 文件，不含執行檔。
